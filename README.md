### 👨‍💻 About Me

I am a passionate **Senior SAP Developer** and **BTP Solution Architect** dedicated to designing and building scalable, enterprise-grade cloud applications. With deep expertise in **ABAP Cloud**, **RAP (RESTful ABAP Programming Model)**, and **SAP BTP**, I focus on delivering clean, modern solutions that align technical excellence with business value.

- 🔭 **Current Focus:** BTP Integration, Clean Core Extensibility, and Event-Driven Architectures.
- 🌱 **Learning & Innovation:** Building Proof of Concepts (POCs) around **Generative AI** and LLM integration within the SAP ecosystem.
- 💬 **Ask me about:** SAP BTP, CAPM, RAP, Clean Core Extensibility, and Cloud Native Development.
- ⚡ **Philosophy:** I believe in continuous learning, keeping up with the evolving tech landscape, and sharing knowledge through blogging.
